Задача: $ARGUMENTS

Следуй правилам `CLAUDE.md` (включая правило согласования). Если что-то неясно, спроси.

1. План (кратко): что меняю, какие файлы, риски (MySQL, парсер логов, деплой). Если в задаче нет «применяй» / «делай», покажи план и жди одобрения.
2. После одобрения: минимальные изменения строго по плану, в стиле существующего кода. Новые файлы добавляй в staging по конкретным путям.
3. Самопроверка:
   - Автоматические проверки: `php -l` по изменённым файлам, `vendor/bin/pint --test`, доступные тесты.
   - Проверка корректности (твой собственный анализ): нет конкатенации ввода в SQL, валидация и mass assignment, N+1, транзакции, у миграций есть `down()`, не нарушены правила из `CLAUDE.md`.
4. Итог: изменённые файлы; какие проверки выполнены, какие пропущены, какие проблемы найдены; что нужно при деплое (миграции, конфиги, `.env`); что осталось.
